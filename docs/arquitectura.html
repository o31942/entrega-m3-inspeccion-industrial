Frontera Desacoplada

El cliente web (:5173) nunca importa Python ni toca pesos del modelo; toda inferencia cruza por red hacia el gateway (:8000) y el servidor gRPC (:50051).

Separación Estricta en 3 Capas

Las capas inference/ y services/ son agnósticas al protocolo (sin grpc ni fastapi), permitiendo pruebas unitarias deterministas sin red.

Gobernanza y MLflow

La misma revisión fija del modelo MaaS servida en gRPC es evaluada y registrada en MLflow Model Registry (http://127.0.0.1:5050).
